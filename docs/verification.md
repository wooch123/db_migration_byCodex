# 검증 기록

## 사내 저장소 호환 설치 검증 (2026-09-10)

- 로컬 HTTP 프록시와 제한된 패키지 저장소를 구성해 실제 pip 요청이 지정한 프록시를 거치는지 확인했습니다. 최신 후보의 `annotated-doc` 의존성을 제공하지 않았을 때 이전 후보와 호환 하위 버전을 선택했고, 가능한 조합이 없을 때는 설치를 중단했습니다.
- Windows Python 3.12의 새 환경에서 `annotated-doc`이 없고 예전 패키지만 있는 wheel 폴더로 `run.bat --setup-only`를 실행했습니다. 고정 버전 설치 오류 후 FastAPI 0.115.14 / Starlette 0.46.2 / Pydantic 2.11.7 / pydantic-settings 2.10.1 / Uvicorn 0.34.3 조합으로 자동 전환해 설치했습니다. 테스트용 저장소 목록은 `tests/fixtures/compatible-mirror.txt`입니다.
- 설치 단계의 가상 Claim 6건 처리·웹 응답 검사가 성공했고, 패키지 저장소를 비활성화한 재실행에서도 저장된 조합을 재사용했습니다.
- 기존 고정 버전 환경과 이전 버전 환경에서 각각 전체 테스트 **79개**가 통과했습니다. 코드 검사와 포맷 검사도 통과했습니다.
- 실제 사내 프록시에는 접속할 수 없어 로컬 프록시와 제한된 저장소로 재현했습니다. 사내 PC에서는 그 PC의 pip 설정과 조회 결과로 버전을 결정합니다.

검증일: 2026-09-09. 로컬 환경: Windows, Python 3.12.14.

## 배포 검증 범위

자동 실행 파일 추가 검증:

- Windows의 비어 있는 별도 프로젝트 폴더에서 `run.bat --setup-only`로 `.venv`, 런타임 21개 패키지, build 도구와 프로젝트 자동 설치 확인.
- 설치된 패키지 하나를 테스트 환경에서 제거한 후 실행 파일이 누락을 감지하고 자동 재설치하는 동작 확인.
- 사용자 설정을 추가한 `.env`의 해시가 설치 전후 동일함을 확인.
- `PIP_NO_INDEX=1` 상태에서 준비된 환경 재사용 및 CLI 실행 확인.
- 로컬 wheelhouse만 사용하는 별도 빈 환경에서 인터넷 패키지 조회 없이 초기 설치 완료.
- 자동 설치한 환경에서 하루치 가상 Claim 6건 검증 완료.
- 공백·`&`·`!`가 포함된 프로젝트 경로, 인자 전달, 종료 코드, 설치 실패 시 앱 실행 중단 테스트 통과.
- Linux 실행 파일 문법 검사 통과. GitHub Actions에서 **Ubuntu/Windows의 초기 설치·네트워크 없는 재실행 검증 모두 통과**.

자동 실행 파일 구현 커밋 `5cc06d19dab2763261b2d031a4a1acc042da24a9`의 [검증 실행 결과](https://github.com/wooch123/db_migration_byCodex/actions/runs/34345749022): Ubuntu Python 3.11/3.12/3.13 전체 테스트 70개, Windows/Ubuntu 실행 파일 검증, 정적 검사와 패키지 빌드가 모두 성공했습니다.

GitHub Actions의 **Ubuntu + Python 3.11/3.12/3.13 세 환경 모두 테스트·정적 검사·패키지 빌드가 성공했습니다.** 검증한 구현 커밋은 `628bf4c69bb5ba2340f8222e100a41f0f48d5ae5`이며 [실행 결과](https://github.com/wooch123/db_migration_byCodex/actions/runs/34344266498)에서 확인할 수 있습니다.

로컬 컴퓨터에는 Ubuntu/WSL과 Docker 실행 환경이 설치되어 있지 않아 systemd 서비스 등록과 Docker 실행은 현지에서 수행하지 않았습니다. 서비스 파일·배포 문서를 제공하며 실제 사내 Ubuntu 환경에서 네트워크·권한·인증서를 함께 확인해야 합니다.

**사내 API에는 접속하지 않았고 운영 DB에 전송하지 않았습니다.** 실제 응답 래퍼, 업무 키, 대상 API의 upsert 지원, null 처리, 성공 확인 응답 및 사내 인증 정보는 사내 전환 검증 대상입니다. [API 계약](api-contracts.md)과 [운영 가이드](operations.md)에 필요한 설정을 정리했습니다.
