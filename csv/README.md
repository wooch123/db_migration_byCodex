# CSV 가져오기 폴더

운영 서버에 전송할 `.csv` 파일을 이 폴더 바로 아래에 넣으세요. 하위 폴더·연결 경로는 읽지 않습니다. 파일을 넣는 것만으로 자동 전송되지는 않습니다.

1. `examples/far_import_template.csv`를 이 폴더로 복사해 필요한 값을 채웁니다. 사용하지 않는 선택 컬럼은 제거해도 됩니다.
2. 웹의 **CSV 가져오기 → 파일 목록 새로고침**에서 파일을 선택합니다.
3. **미리보기**로 헤더 매핑·전송 JSON·오류 행을 확인합니다.
4. **전송 없이 검증** 또는 **API 전송**을 실행합니다. 결과와 HTTP 요청·응답은 기존 실행 이력에 기록됩니다.

`far`, `sample`은 모든 행에 필요합니다. 나머지 필드는 입력한 것만 보냅니다. 빈칸은 기본적으로 전송에서 제외하며 화면에서 `null` 전송을 선택할 수도 있습니다. 숫자처럼 보이는 식별자의 앞자리 0은 그대로 보존합니다. Excel에서 이미 0을 없앴거나 긴 숫자를 반올림한 파일은 복원할 수 없으므로 식별자 컬럼을 텍스트 형식으로 저장하세요.

UTF-8(BOM 포함) 또는 Windows CP949 인코딩을 지원합니다. CSV 데이터 파일은 Git과 Docker 빌드에 포함되지 않습니다. 이 안내 파일과 `.gitkeep`만 Git으로 관리합니다. 자세한 매핑·실행 방법은 [CSV 가져오기 안내](../docs/csv-import.md)를 참고하세요.
